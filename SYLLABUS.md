# Course Syllabus: Interview Prep, Taught

**Goal:** after watching, you can answer every one of the 169 interview questions in `scripts/` (q01–q100, sw01–12, be01–15, cp01–24, fe01–12, ai01–06) out loud, with an example, for micro1 interviews: Backend SWE, SWE, Competitive Coder / DSA, Frontend, AI Eval and C++.

**Format:** 48 lessons, 6–12 min each (dense lessons up to 12). Each lesson teaches one idea from the ground up around one worked example, then drills the interview questions listed in `covers`. Every question id appears in exactly one lesson (`node coverage.mjs --syllabus` checks this).

**Render order:** SWE → Backend → DSA → Frontend → AI Eval → C++. Inside a track, lessons are a learning path: watch them in order.
